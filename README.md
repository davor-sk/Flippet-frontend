Flippet je web aplikacija za učenje uz pomoć digitalnih kartica. Aplikacija omogućuje korisnicima kreiranje vlastitih kolekcija kartica s pojmovima i definicijama, pretraživanje javnih kolekcija te interaktivno učenje uz animirani sustav okretanja kartica. 

Ključne funkcionalnosti:
- Registracija/prijava korisnika
- Odabir kolekcije kartica
- Kreiranje i upravljanje kolekcijama kartica
- Interaktivno učenje uz 3D flip animaciju kartica
- Praćenje rezultata učenja (naučeno / nenaučeno, postotak, vrijeme)
- Pretraživanje javnih kolekcija po naslovu ili kategoriji
- Glasovni unos teksta za kartice (speech-to-text)
- Responzivni dizajn za mobilne i desktop uređaje
